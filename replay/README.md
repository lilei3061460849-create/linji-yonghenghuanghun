# 战局回放（第一版）

这是供开发者自用的极简战斗回放器。它读取引擎已记录的战斗事件，不重新执行 AI、随机数或战斗结算。

## 1. 导出回放数据

在项目根目录运行：

```bash
python tools/export_replay.py --slot current --output replay.json
```

默认导出存档 `current` 中最新一场战斗。指定历史场次：

```bash
python tools/export_replay.py --slot current --battle 3 --output replay-3.json
```

如果存档目录不同，可追加 `--save-dir 路径`。回放数据只包含该场战斗的事件流。当前角色面板显示的是导出时的最终状态，不应误读为历史每一回合的状态。

## 2. 打开播放器

打开本目录的 `index.html)，点击「打开 replay.json」，选择刚导出的文件。播放器支持手机触控、上一/下一事件、播放/暂停、倍速、时间轴跳转与事件详情。

如果你的开发环境不允许直接打开本地 HTML，可在项目根目录启动静态文件服务器：

```bash
python -m http.server 8000
```

然后在同一运行环境中打开 `/replay/` 路径。页面会自动尝试读取项目根目录的 `replay.json`，因此不必把远程文件先下载到手机。如果 Python 运行在远程容器中，需要通过开发平台的端口转发功能从手机访问该端口。单纯在 GitHub 文件页面查看 HTML 不会运行播放器。

## 第一版范围

- 用两个战斗位置展示当前事件的行动者与目标。
- 以事件列表、攻击连线和实际结算数值解释战斗。
- 支持从 JSON 文件载入，不要求部署前端框架或新增运行时依赖。
- 暂不包含世界地图坐标、视频导出或每种道纹的专属动画。世界地图接入后，再将战斗事件面板嵌入地图回放。
