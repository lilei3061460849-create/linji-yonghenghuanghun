# 手机战局回放（第一阶段）

当前版本先回放引擎已有的战斗事件；地图坐标与世界边界尚未接入。战斗双方显示在左右两格，攻击、闪避、伤害、治疗、状态变化和死亡等事件按引擎登记顺序逐条显示。

## 导出回放

在你现有的游戏运行代码中，副本或战斗结束后调用：

```python
from engine.replay import export_replay

# engine 是当前正在运行的 GameEngine 实例
result = export_replay(engine, "replay.json")
print(result)
```

也可以传入 `engine.state`。导出只读取 `state.combat_events`，不会重跑 AI、随机数或战斗结算。若你通过其他 API/命令启动游戏，只需在持有 `GameEngine` 实例的地方调用一次。

## 在手机上观看

1. 打开 `replay/index.html`，或者将这个静态页面部署到能从手机访问的网页托管服务。
2. 点「导入回放」，选择导出的 `replay.json`。
3. 用播放/暂停、倍速、时间轴或事件列表逐条复盘。

页面不依赖第三方 JS 库。浏览器出于安全限制可能不允许直接从 GitHub 仓库页面执行本地 HTML；若要长期从手机访问，需要把 `replay/` 作为静态网页托管。第一阶段不生成 MP4。

## 当前范围

- 已支持：战斗事件导出、事件顺序、事件详情、角色参与者快照、手机响应式界面。
- 尚未接入：世界地图坐标、移动路径、副本整体边界收缩、按角色过滤、MP4 导出。
