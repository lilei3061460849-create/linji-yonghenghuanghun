# 扭曲都市地图原型：事件到地点映射

依据 `副本/扭曲都市.md`。这是设计与 UI 原型说明，不改变副本规则或事件结算。

## 世界观硬约束

扭曲都市已沦为末日废土，不存在正常营业的公司、商店、医院或公共机构。普通人类是幸存者，可能聚落、躲藏或外出搜集物资。出现在工厂、仓库、控制室和车辆旁的人，是临时利用废弃设施的幸存者，不是仍在履行职位的员工。残余设备可由备用电源、法力或系统短暂运转，但默认无人维护。

因此，现代建筑作为废墟遗迹存在是合理的；“仍正常运营的现代都市服务”不合理。地图不添加与副本背景冲突的原始部落。

## 专属事件地点

| 原事件 | 地图地点 | 处理 |
|---|---|---|
| 医生 | 废弃医院遗迹中的临时手术间 | 保留原选项与代价；医生是癫狂微光者，不是医院正常在职医生。 |
| 恶魔医务室 | 废弃医院遗迹深处、被占据的地下手术间 | 原通用事件「手术」改归扭曲都市专属事件；保留强制移植、抽取灵魂与拒绝三项及原结算。致敬名保留为「恶魔医务室」。 |
| 乞丐 | 街角、坍塌建筑避难处或废弃公交站 | 街头遭遇，保留庇护、施舍、终结、无视四个选项。 |
| 血肉温室 | 破碎玻璃温室或废弃植物研究设施 | 保留三种采集选择与拒绝选项。 |
| 绝望来电 | 被猩红真菌覆盖的铸铁公用电话亭 | 地点互动；必须抵达电话亭才可触发后续。 |
| 皮衣店 | 废弃服装店或被异化裁缝占据的改衣作坊 | 保留试穿、购买、交换、拒绝；不表现为正常营业商店。 |
| 生锈邮筒 | 倒塌街区旁的旧邮筒 | 地点互动；写信选项保留最多 40 字与流血 5 的原规则。 |
| 尖叫下水道 | 排水井口与地下排水/市政管线入口 | 保留拥有五种道纹及以上的门槛与原选项；“有轨”细节后续核对是否确有设定依据，不在原型里擅自补造轨道系统。 |

## 通用事件：共享机制，场景外壳适配副本

事件池不能只包含扭曲都市专属事件。当前地图原型展示 8 个通用事件与 8 个扭曲都市普通专属事件。通用事件在每个副本中都应保持相同的事件身份、选项和结算效果；只允许地点外观、感官描写与进入场景的过渡根据副本环境调整。

| 通用事件 | 扭曲都市中的地点呈现 | 跨副本适配原则 |
|---|---|---|
| 无名冢 | 不再出现在扭曲都市地图 | 已从通用事件池移出，归入乱葬岗专属事件。 |
| 遗忘书屋 | 坍塌建筑内的旧书与档案空间 | 核心是三本古籍及其效果；可改成档案室、藏经处或残存资料库，不改选项结算。 |
| 祭坛 | 废墟广场中的黑石祭坛 | 仅提供碎片投资：15%暴涨净赚4X、25%上涨净赚X、35%崩盘净亏X、25%黑天鹅净亏3X并直接扣除额外2X；每次抵达最多投资一次。遗物交易不属于祭坛功能。 |
| 过路商人 | 道路交汇处的临时货摊 | 提供遗物自由买卖；双方协商并在成交前确认交易双方、遗物名称和碎片价格。交易成功后立即转移，不得复制遗物，买方不得透支碎片。 |
| 猩红暴雨 | 腐蚀性异色雨幕与积水街道 | 核心是面对环境灾害的三种应对代价；未来重做通用事件时，应评估“猩红”是否过度绑定某一世界观。 |
| 无名碑林 | 被苔藓与裂纹覆盖的纪念碑群 | 核心是触碰遗留执念并获得曲解；可换成刻痕、铭文、记忆载体等环境化表现。 |
| 回音长廊 | 废弃建筑中的破碎镜廊 | 核心是面对轮回死亡回声并改变《死者之书》；镜子与长廊可替换成其他能呈现回声的媒介。 |
| 回忆当铺 | 无门的地下交易柜台 | 核心是典当或赎回前世记忆；柜台、交易仪式和商人形态可适配副本。 |
| 手术 | 已移出通用事件池 | 改归扭曲都市专属事件，名称为「恶魔医务室」。 |
| 无魂泥潭 | 沥青坑与蠕动黑泥 | 核心是采集可屏蔽灵魂位置的绝息淤泥；环境外观可变，但道具效果与代价不变。 |

这张表是**地点适配层**，不是通用事件规则重写。祭坛投资与过路商人遗物交易按《规则正文.md》的当前规则呈现。动态还债阈值按每名角色本局历史最高碎片余额 M 计算：余额 B≤-(10+M) 时触发；M 只增不减。

## 不作为地图地点的事件

- **都市的终音**：扭曲都市死斗后强制触发的四选一奖励，继续由死斗结果触发。
- **初拥之夜**：与获得猩红尖牙、持有该遗物后击杀血族等条件关联，继续按角色状态/行为触发，不要求寻找固定建筑。

## 专属行动：维修

维修不是上述专属事件之一。可以在地图表现上关联配电室、设备间或废弃机械设施，但不得擅自改写行动规则：立即完成，消耗 1 个世界回合，不额外锁定后续行动。维修的地点外观不应被误认为新增前置条件，除非之后明确裁定改规则。

## 当前原型范围

- 固定 21×21 基础方格；道路以规律网格保证道路网络连通。
- 街区内建筑占地、瓦砾、杂草和积水随机变化，地图总格数固定，地形比例允许变化。
- 事件地点在地图上随机分配，用于审查建筑与事件是否匹配。
- 收缩时每次隐藏最外一圈有效格，坐标保持原始网格坐标。
- 当前只是独立 HTML 原型：当前展示 8 个通用事件与 8 个普通专属事件以便审查映射，不代表实际副本每局都会生成全部事件；没有接入真实移动、寻路、事件触发、存档或回放状态。


## 本轮事件归类调整

- 「手术」改名为「恶魔医务室」，归入扭曲都市专属事件；现有两条有效选项与拒绝选项、代价和结算保持不变。
- 「无名冢」从通用事件池移出，归入乱葬岗专属事件，不再在扭曲都市地图中生成。
- 「祭坛」改为碎片投资，保留四档随机概率与净变化；不提供遗物交易。
- 「过路商人」承接遗物自由买卖功能，交易价格由双方协商并在成交前确认。
- 「还债」阈值改为各角色本局历史最高碎片余额 M 的 10+M；真实余额 B≤-(10+M) 时触发，黑天鹅额外债务直接计入真实余额。
