# 扭曲都市地图原型：事件到地点映射

依据 `副本/扭曲都市.md`。这是设计与 UI 原型说明，不改变副本规则或事件结算。

## 世界观硬约束

扭曲都市已沦为末日废土，不存在正常营业的公司、商店、医院或公共机构。普通人类是幸存者，可能聚落、躲藏或外出搜集物资。出现在工厂、仓库、控制室和车辆旁的人，是临时利用废弃设施的幸存者，不是仍在履行职位的员工。残余设备可由备用电源、法力或系统短暂运转，但默认无人维护。

因此，现代建筑作为废墟遗迹存在是合理的；“仍正常运营的现代都市服务”不合理。地图不添加与副本背景冲突的原始部落。

## 专属事件地点

| 原事件 | 地图地点 | 处理 |
|---|---|---|
| 医生 | 废弃医院遗迹中的临时手术间 | 保留原选项与代价；医生是癫狂微光者，不是医院正常在职医生。 |
| 乞丐 | 街角、坍塌建筑避难处或废弃公交站 | 街头遭遇，保留庇护、施舍、终结、无视四个选项。 |
| 血肉温室 | 破碎玻璃温室或废弃植物研究设施 | 保留三种采集选择与拒绝选项。 |
| 绝望来电 | 被猩红真菌覆盖的铸铁公用电话亭 | 地点互动；必须抵达电话亭才可触发后续。 |
| 皮衣店 | 废弃服装店或被异化裁缝占据的改衣作坊 | 保留试穿、购买、交换、拒绝；不表现为正常营业商店。 |
| 生锈邮筒 | 倒塌街区旁的旧邮筒 | 地点互动；写信选项保留最多 40 字与流血 5 的原规则。 |
| 尖叫下水道 | 排水井口与地下排水/市政管线入口 | 保留拥有五种道纹及以上的门槛与原选项；“有轨”细节后续核对是否确有设定依据，不在原型里擅自补造轨道系统。 |

## 不作为地图地点的事件

- **都市的终音**：扭曲都市死斗后强制触发的四选一奖励，继续由死斗结果触发。
- **初拥之夜**：与获得猩红尖牙、持有该遗物后击杀血族等条件关联，继续按角色状态/行为触发，不要求寻找固定建筑。

## 专属行动：维修

维修不是上述专属事件之一。可以在地图表现上关联配电室、设备间或废弃机械设施，但不得擅自改写行动规则：立即完成，消耗 1 个世界回合，不额外锁定后续行动。维修的地点外观不应被误认为新增前置条件，除非之后明确裁定改规则。

## 当前原型范围

- 固定 21×21 基础方格；道路以规律网格保证道路网络连通。
- 街区内建筑占地、瓦砾、杂草和积水随机变化，地图总格数固定，地形比例允许变化。
- 事件地点在地图上随机分配，用于审查建筑与事件是否匹配。
- 收缩时每次隐藏最外一圈有效格，坐标保持原始网格坐标。
- 当前只是独立 HTML 原型：所有七个地点都会出现以便审查映射，不代表实际副本每局都会生成全部事件；没有接入真实移动、寻路、事件触发、存档或回放状态。
