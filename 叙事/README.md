# 叙事文件

本目录存放用户供稿的**叙事正文**（剧情叙述与台词），按用户指定顺序收录：

| 序 | 文件 | 原稿 | 幕数 |
| --- | --- | --- | --- |
| 1 | [愚者.md](愚者.md) | `愚者.txt` | 序幕 + 五幕 |
| 2 | [珍惜.md](珍惜.md) | `珍惜.txt` | 十一幕 |
| 3 | [珍惜2.md](珍惜2.md) | `珍惜2.txt` | 六幕 |

## 收录约定

- 正文**一字不差**照录用户原稿，不改写、不加标题、不删减、不补标点。
- 唯一处理：换行符由 CRLF 统一为 LF（Markdown 仓库通用口径），文字内容零改动。
- 该目录是叙事层，**不是规则事实源**：其中的数值、机制描述与人物认知不覆盖《规则正文》与引擎结算，也不作为战报或测试证据。
- 后续追加的叙事稿按用户给定顺序续编号，新文件不改动既有文件。
