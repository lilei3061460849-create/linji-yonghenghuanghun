# 叙事文件

本目录存放用户供稿的**叙事正文**（剧情叙述与台词），按用户指定顺序收录：

| 序 | 文件 | 幕数 |
| --- | --- | --- |
| 1 | [愚者.txt](愚者.txt) | 序幕 + 五幕 |
| 2 | [珍惜.txt](珍惜.txt) | 十一幕 |
| 3 | [珍惜2.txt](珍惜2.txt) | 六幕 |

## 收录约定

- 正文**一字不差**照录用户原稿：文件为字节级原样复制（含原有 CRLF 换行），不改写、不加标题、不删减、不补标点。
- 因此本目录正文保留 `.txt` 后缀：仓库的仓库级 Markdown 校验（`engine/document_validation.py`）要求每个 `.md` 都有 H1 一级标题，给叙事稿加标题会破坏「一字不差」，故不以 `.md` 收录。
- 本目录是**叙事层，不是规则事实源**：其中的数值、机制描述与人物认知不覆盖《规则正文》与引擎结算，也不作为战报或测试证据。
- 后续追加的叙事稿按用户给定顺序续编号，新文件不改动既有文件。
