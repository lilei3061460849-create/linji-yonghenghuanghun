# 灵记-第四宇宙

> **入口与速览，不是规则正本。**
>
> 玩家先读《死者之书》的六条底层逻辑；需要精确结算时读《规则正文》；AI 与维护者按
> 「事实源 → 引擎 → 测试」的链路工作。README 故意不复述会变动的中文条文。

## 给玩家的起点

《死者之书》的「规则」页只留下六条不会改变的底层逻辑：

1. **自由**：众生自由，无不可为。
2. **随机数**：身负因果，混沌自现。
3. **整数**：凡有微芒，尽归圆满。
4. **自由控 X**：随心而动，无心无动。
5. **属性上限**：身如瓦器，溢者归虚。
6. **代价**：代价无形，亦无可避。

它们是进入第四宇宙前应当知道的事；它们不是逐项操作手册。

它只打包文字描述、规则逻辑与世界观：通用规则、开局与流程、道纹、物品、法术、已实现副本、

均已剔除；它不是新的规则正本，修改任何来源后须由生成器重建。

## AI / 维护入口（非规范速览）

```text
canonical_rules  = 规则正文.md          # 精确结算条文、通用道纹、通用事件
playbook         = 推演规范.md          # 开局/战斗/死斗/战报的完整流程
invariants       = 死者之书.md          # 6 条稳定逻辑；特殊事件的生成页
runtime_truth    = engine/              # 最终实际结算
structured_rules = data/rules/*.toml    # 已迁移的结构化规则源
validation       = tests/                # 文档、数据、引擎三方一致性
```

- **不要**从《死者之书》的压缩讲述反推数值、目标限制或时序；它刻意省略会变细则。
- **不要**从遗言反推规则；遗言署真人姓名，可能有真假。
- 规则冲突时按这个优先级处理：用户最新裁定 → 引擎实际结算 → 结构化事实源 → 《规则正文》 → 速览与叙事文本。
- 改规则先定位其事实源；改完必须更新派生文档并跑对应测试。完整约束见 [AI 知识库](AI_EXPERIENCE.md)。

## 可玩网页界面

```bash
python3 webapp/server.py      # 默认 http://0.0.0.0:8000/
```

单页地图界面：点相邻格或用 WASD/方向键移动，等待回合，与相邻单位交涉，
向朋友/员工**建议**行为（采纳与否由对方自己按引擎判定），并在遭遇时打完一场战斗。
界面只显示引擎已公开的迷雾信息；所有结算仍走 `GameEngine.execute_action`。
