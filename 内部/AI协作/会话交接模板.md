## 新会话恢复提示词

你正在继续维护第四宇宙项目。请先读取仓库根目录 `README.md`、`AGENTS.md`、`内部/AI协作/README.md` 和 `内部/AI协作/设计决策与纠错索引.md`。然后检查 GitHub 当前打开的 Issue / PR 和最近相关 Actions。根据本轮任务读取正式事实源、实现和测试，不要仅依赖聊天摘要或 `AI_CONTEXT.md`。严格区分已确认、已实装、待实装、待讨论和已否决；不得自行补造用户未规定的条件。修改前检查分支与远端基线，遵守 AGENTS.md 的 PR、备份、最小修改和验证规范。任务状态只写入 Issue / PR，不另建平行待办文件。任何规则冲突先停止并请求用户裁定。
