# 内部资料

这个文件夹放**玩家不需要看的东西**：审查与排查报告、废稿、机制迁移台账、法术 DSL 写法、
触发时机接线状态。查游戏内容请回根目录的《规则正文》《全道纹索引》《物品索引》《法术索引》《副本索引》。

## 有什么

| 目录／文件 | 内容 |
| --- | --- |
| `审查报告/` | 各轮道纹／供能／副本审查、静态排查报告、裁定落地核查、道纹效果汇总、审查清单 JSON |
| [废稿汇总.md](废稿汇总.md) | 已否决或已撤掉的设计及其淘汰原因（防止换个名字重推） |
| `archive/` | 更早的历史档案：旧裁定、迁移记录、已废止假设 |
| [机制迁移台账.md](机制迁移台账.md) | 规则从文档迁进引擎／结构化数据源的逐条台账 |
| [法术写法与接线.md](法术写法与接线.md) | 自定义法术的 DSL 语法、解析器行为、各触发时机是否真的接入结算 |
| [道纹统一规则迁移规范.md](道纹统一规则迁移规范.md) | 道纹伤害规则迁进 `engine/rule_engine.py` 的范围、阶段边界与扩展规范（原放 `engine/`，2026-11-03 移到内部资料） |
| [整改记录-2026-11-03.md](整改记录-2026-11-03.md) | 本轮体检整改的存档：安全核查结论、结构性改动、32 个提交、需要裁定的 4 件事 |
| [行动分组清单-2026-11-03.md](行动分组清单-2026-11-03.md) | 74 个 action 的分组、处理器位置与是否已进注册表（`tools/gen_action_inventory.py` 生成，勿手改） |

## 约定

- 工程实现细节、审计编号、改名历史、迁移状态写在这里或代码注释里，不写进查询文件。
- 这里的报告是**当时**的快照，结论可能已被后续裁定推翻；现行规则以根目录事实源为准。
