# webapp · 可玩网页界面

把引擎的开放世界接口包成 HTTP + 一张单页地图。界面只负责显示与转发，
所有判定仍由 `GameEngine.execute_action` 完成。

## 启动

```bash
python3 webapp/server.py              # 默认 127.0.0.1:8000，只监听本机
PORT=9000 python3 webapp/server.py    # 换端口，仍然只监听本机
HOST=0.0.0.0 python3 webapp/server.py # 对外开放（风险见下）
```

### 安全说明：默认只监听本机

- 本界面**没有任何鉴权**：没有登录、没有会话 ID、没有 CSRF 防护；
- 进程里只有**一个全局会话**（`SESSION`），`POST /api/new` 会直接覆盖当前这一局；
- 因此默认 `HOST=127.0.0.1`。设成 `0.0.0.0` 后，同一网络内的任何人都能开局、
  操作你的角色、读你的存档视图。只在可信局域网、且明确知道风险时使用，
  并建议用防火墙限制来源。
- 存档使用 pickle 反序列化，**只读自己本机生成的存档**，不要接收外部上传的存档文件。

只依赖 Python 标准库，不需要 `pip install`。

## 角色演武场（`/lab`）

想跳过随机开局、直接捏角色再开打，用演武场：

```text
http://127.0.0.1:8000/lab
```

界面分两页：

- **角色库**：新建 / 修改 / 删除角色卡。每张卡保存名字、三维、资源（碎片/精力/残韵）、
  道纹、遗物、消耗品。角色卡是**配方**，不存引擎对象；存档写到
  `data/player_characters.json`（可用 `LINJI_CHARACTERS_FILE` 改路径），
  写入走临时文件 + `os.replace`。
- **GitHub 同步**：保存/删除后自动把该文件提交并推送到**当前分支**
  （`git commit -- data/player_characters.json` + `git push origin <当前分支>`），
  换设备只需回到同一分支/会话即可取回。同步失败不会丢本机数据，界面上会显示原因，
  并提供「同步到 GitHub」手动重试按钮。注意：本仓库是公开的，角色卡内容会公开可见；
  也不要在角色卡里写真实姓名等隐私。
- **A vs B 对战（2026-11-10 用户令：空白开局）**：对战区初始全空白，点
  「＋ 加入单位」从**角色库**或**当前怪物池**逐个挑（选择窗口与角色库/道纹
  同款：固定高度＋内部滚动＋搜索框）；每个单位一行，行上随时切 A/B 侧、移除。
  A 侧第一张角色卡就是主控（驱动轮回者侧），其余单位全是该侧队友——卡队友
  与怪物队友都进对应侧（A 侧队友进 `state.friends`，B 侧卡队友成额外对手、
  怪物队友并入敌方）；B 侧可以全怪物。**所有大列表已统一**：角色库、对战单位、
  加入窗口、道纹/遗物/消耗品选择器全是固定高度＋上下滑动＋搜索框。
  开战后**自动跳进战斗界面**并自动「开始本回合」，不用再手点。
- **阵营自选（2026-11-10 用户令）**：每张角色卡可选阵营 **轮回者 / 怪物**，选了
  什么阵营就按那个阵营的逻辑运行。**侧位就是 A/B 槽位，阵营只是单位类型**，
  不按槽位硬编码、不限制组合：轮回者打轮回者、怪物打怪物、轮回者+怪物队友打
  轮回者……照摆。A 卡是怪物时，你操作的玩家实体转为怪物（`entity_type="怪物"`：
  痛苦的偏爱、怪物道纹判定等同口径，与 `Entity.__post_init__` 怪物分支一致）；
  B 卡是怪物时造成怪物对手。两侧还能各带**怪物队友**（最多 6 名，A 侧进
  `state.friends` 与 [朋友] 同机制——能被选中、能挡刀、不占你的出手；B 侧并入
  敌方）。战斗卡上每个单位名旁都有阵营徽标。消耗品的使用者也随摆位走
  （`actor_ref`）：任何参战单位都用**自己携带的**消耗品，主动与被动（应对窗口）
  同口径。
- **演武场不入副本（2026-11-10 用户令）**：演武场是特殊场景，不触发
  `setup_choose_region` 的进副本流程——「进副本须持有一件遗物」等副本规则在
  这里不适用；没选遗物就一件都没有（开局随机发现只是候选，不显式挑选就放弃），
  副本名只决定「怪物池」口径。

三维口径：

- **规则模式**：仍按 25 点预算（1 点 = 6 血限，2 点 = 1 速限 = 1 法限、须为偶数）；
- **自由模式**：直接填血限/速限/法限，只在演武场生效，不写回任何规则或事实源。

其他口径：

- 道纹名单只取 `DaoWenEngine.list_all()`（运行时已注册），出生自带的【透支】不在勾选列表；
- 遗物按 `ceil(血限/30)` 分配启用槽位，超出的照常持有但停用；
- 消耗品可逐件设耐久，名单只来自工具库、事件消耗品与翼类；
- 指定对手（角色或怪物）都会建一张小地图、把对手摆到玩家身边并登记真实遭遇，
  结算仍走 `battle_start`；随机开战则沿用引擎自己的出怪我配方；
- B 方角色卡的遗物**真实生效**（轮回者阵营卡时）：写入引擎的 `state.opponent_relics`
  （敌方轮回者通道，死斗同款），战斗中的持有判定走 `state.side_has` / `_relic_active`，
  启用槽位同样是 `ceil(血限/30)`。遗物效果按**持有者阵营**结算：`回锋刀`（含[回始]）、
  `减速`、`忘忧香`、`同魂笔` 均已与 A 方对称。仅 `无所求`（事件选项）依赖玩家交互动作，
  B 方没有对应动作，故仍只对 A 方可用。怪物阵营卡的对手的遗物只挂在实体自己身上
  （怪物口径按自带名单回退读取），不走 opponent_relics 通道。
- **推演模式（`manual_both`）**：对战默认开启——双方都由用户操作，B 方回合不再调用
  AI 启发式。A 方出手后引擎按「交替出手」自动把优先权交给 B 方，战斗界面出现
  「① 准备 B 方行动」→ 选目标/道纹/闪避 →「执行 B 方行动」，结算后自动换回 A 方。
  想恢复旧行为（AI 打 B 方）取消勾选即可。

> 演武场与手动开局共用同一个进程会话：`POST /api/lab/start`、`POST /api/lab/duel`
> 都会覆盖当前对局。

## 能做什么

- **移动/等待**：点相邻格或 WASD／方向键；每步推进世界时间，云雾按玩家视野揭开。
- **交涉**：相邻格的朋友、员工、商人、其他轮回者可交谈/交易/合作/威吓/动手。
- **建议同伴**：朋友与员工在地图上自主行动（默认跟随）。玩家只能建议
  `follow` / `guard` / `explore` / `hold`，是否照做由该单位按
  `engine/world.py::suggestion_acceptance_percent` 判定，拒绝时行为保持不变。
- **战斗（统一行动菜单，2026-11-10 用户令）**：轮到谁，战斗卡该单位名字旁
  只有一个「行动」按钮；点开是同一套行动菜单——攻击（逐击）、施法
  （单发/组合/协力）、聚能、消耗品、残韵、同伴（真有同伴才出现）、特殊
  （遗物技/自定义法术等）、结束回合、危险区（逃跑/重来）。菜单按引擎
  `available_actions` 动态生成，该角色没有的类目整行消失；A 方与 B 方
  （推演模式）同一套界面；每个行动全界面只有一个入口。B 方「准备行动」后引擎
  仍返回标准 actions 列表（resolve_monster_phase + 结束回合），菜单不会变空
  （2026-11-10 修复：旧形状缺 actions 键，曾显示「引擎当前没有可选战斗行动」）。许愿不进菜单
  （叙事行动，真要加东西走控制台）。逐击应对窗口里，被选中的一方还能**先用一件
  消耗品再选应对**（2026-11-10 用户令：消耗品=主动且被动行动；不耗出手也不耗
  应对，本击窗口保持开放；【必中】次数覆盖本击时随被动行动一起被锁）。底部公共区只有流程按钮（开始/结算回合、
  结算战斗、非推演的敌方阶段）与「保存战斗并退出」。战斗状态变化时页面会
  自动把战斗卡滚进视野。
- **待决弹窗**：发现/三选一类（衍生领取、遗物与消耗品发现、典当领取、救赎、
  员工转化道纹）不占行动菜单——自动弹窗直接点选；「暂不处理」收起后可从
  顶部「待决」按钮再打开。只认**真实待决**（`available≠false`）：引擎在战斗里
  永远列着一条典当占位条目（`available:false, remaining_groups:0`），那不是
  待决，不弹窗（2026-11-10 修复：此前每次渲染都会误弹）。
- **存档架**：战斗卡底部「保存当前战斗并退出」先存档再退出对局（回合、双方
  状态、战斗运行态完整保存）；顶部「存档架」随时读取继续或删除存档，
  不用重开战斗重调三维。同一会话内必可读回；常规开局（存档落盘
  `data/saves/`，已 gitignore）跨进程重启也能读回。
- **施法（2026-11-10 用户令：施法 = 发动道纹）**：行动菜单「施法」里的
  三个页签——
  - **单发**：直接发动一枚道纹（原「发动道纹」入口：选道纹、X、目标、
    闪避/血影，特殊道纹的额外参数走附加参数 JSON；同伴道纹带 `actor_ref`）；
  - **组合**：槽位编辑器——「道纹空格 +（条件）分支」，空格＝空白直接跳过，
    界面生成流程文本与 steps 一次性提交瞬发法术；每个实际效果步骤各扣 1 次出手，
    步骤间留敌方行动空档；
  - **协力**：发起 N 个空位的协力法术（发起不花出手），场上**任意存活角色
    （双方都可以）**往空位填入道纹，每格花填入者 1 次出手；施法者随时
    「发动」（空位＝空白跳过，发动不再扣手；其他角色填入的道纹由施法者借入
    结算、事后归还）或「取消」（已填的出手不退）。条件分支用
    「若<条件>则(…)否则(…)」句式（主语限自身/施法者）。
  轮到谁，战斗卡该单位名字旁就有「普攻 / 施法」快捷按钮（行动导向）。
- **事件**：地点事件按引擎给出的选项结算；需要额外参数的选项可在
  「附加参数 JSON」里补，例如 `{"resonance_type":"转换"}`。
- **高级指令**：侧栏可直接提交任意引擎 action（施法、道纹、消耗品等）。
- **控制台（调试）**：侧栏可直接改引擎状态——全局（回合数/场次/精力/
  碎片/假碎片）与双方全部单位（三维上限与当前值、已用出手、格挡、碎片、
  存活/离场）。直接赋值绕过规则结算与代价，仅供调试；改动会记进行动记录。

## 接口

| 方法与路径 | 作用 |
|---|---|
| `GET /` | 单页界面 |
| `GET /lab` | 角色演武场（自定义三维/道纹/遗物/消耗品并直接开战） |
| `GET /api/lab/options` | 演武场可选项（副本与怪物、道纹分组、遗物、消耗品） |
| `GET /api/lab/characters` | 角色卡列表（按修改时间倒序） |
| `POST /api/lab/characters/save` | 新增或按 `id` 修改一张角色卡 |
| `POST /api/lab/characters/delete` | 删除角色卡（`{id}`） |
| `GET /api/lab/sync` | GitHub 同步状态（仓库/分支/最近一次结果） |
| `POST /api/lab/sync` | 手动把角色卡提交并推送到当前分支 |
| `POST /api/lab/start` | 按配装单人开局；`start_battle=true` 时直接进入战斗 |
| `POST /api/lab/duel` | A vs B：`{a, b, region, width, height, seed}`，B 可为角色卡或怪物 |
| `GET /api/snapshot` | 当前快照（玩家、迷雾地图、同伴、战斗、事件、日志） |
| `POST /api/new` | 开局：属性/副本/地图尺寸（不再送演示同伴，2026-11-04） |
| `POST /api/action` | `{action, params}` 直接调用引擎 |
| `POST /api/ui_attack` | 用当前 `prepare_attack` 快照提交逐击伤害 |
| `POST /api/ui_monster_phase` | 生成合法怪物阶段提交并结算（可带 `dodge_refs`） |
| `GET /api/battle/saves` | 存档架列表（会话暂存 + 磁盘存档） |
| `POST /api/battle/save` | `{slot}` 保存当前对局并退出（快照含战斗运行态） |
| `POST /api/battle/load` | `{slot}` 读取存档继续 |
| `POST /api/battle/save/delete` | `{slot}` 删除存档 |
| `GET /api/debug/state` | 控制台读数：全局变量 + 双方全部单位的可调字段 |
| `POST /api/debug/set` | 控制台写操作：`{global, entity_ref, fields}` 直接改引擎状态（绕过规则结算，仅供调试） |

## 口径

- 单进程单局：`POST /api/new` 会替换当前对局。
- 快照只下发 `world_status`/`world_vision` 已公开的信息，不把全地图交给浏览器。
- 事件待结算时地图冻结，沿用上一帧视图（`world.stale=true`）。
- 开局默认自动选第一件遗物、第一枚道纹，共鸣取「转换」；这是界面层的省事默认，
  不改变引擎规则。
