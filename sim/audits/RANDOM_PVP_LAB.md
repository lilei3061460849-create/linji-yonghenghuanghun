# 随机轮回者 PvP 实验室

## 目的

用真实引擎让两名随机构筑的轮回者互相死斗，观察不同三维分配、遗物与初始道纹的自然克制关系。实验不预设胜者，也不修改战斗规则。

## 当前默认流派对照

| 流派 | 属性点（血/速/法） | 流派道纹 | 遗物 |
|---|---:|---|---:|
| 高速爆发 | 5/14/6（25） | 连击、超频、弱化 | 随机2件 |
| 持续续航 | 13/6/6（25） | 自愈、献锋、疯长 | 随机2件 |

双方均额外保留出生道纹【透支】，因此各持有4种道纹。遗物从真实遗物池无重复抽取；研究构筑注入不代表正式成长途径。

## 当前构筑口径

- 每名角色总属性点预算固定为 **25**。
- 三维为血限点、速限点、法限点；速限和法限按现行规则使用偶数点计价。
- 为避免零攻击力／零攻次角色在开局即失去有效对抗能力，当前随机范围要求血限点至少1、速限点至少2、法限点至少2。
- 同一场对局的两名角色从合法三维分配中无放回随机抽取，保证总点数相同、三维分配不同。
- 每名角色先通过真实开局 action 创建角色，再注入预设流派道纹，并从真实遗物池随机抽取2件，并随机选择残韵。
- 角色出生自带【透支】；因此当前每名角色持有出生【透支】＋3种流派道纹。
- 双方进入现有 `sim.duel_pvp.run_duel_pvp`，按真实引擎 PvP 规则逐手交替；双方使用同一套 `TacticalAI`。不是生产 LLM AI。
- 先手按速限、法限、血限、当前生命依次比较；完全相同则用种子确定首回合先手，并沿用规则的交替先手。
- 每局记录构筑、AI 行动日志、完整 `GameEngine` action history、战斗事件数、胜负与异常。相同 seed 可复现。

## 已发现的问题与修复

| 编号 | 现象／问题 | 修复或处理 |
|---|---|---|
| P-012 | 初始随机分配可能抽到0法限或0速限，角色缺乏有效攻力／攻次，出现零对抗局 | 随机范围增加最低资源约束：血限点≥1、速限点≥2、法限点≥2 |
| P-013 | 两个独立随机源可能偶然抽到完全相同的三维分配 | 同一对局内从合法分配列表无放回抽取两套 |
| P-014 | 默认 WinOnlyAI 对每手候选进行整局胜负推演，随机对局批次运行成本较高 | 当前实验双方统一使用 TacticalAI；保留 WinOnlyAI 作为后续高成本对照选项 |
| P-015 | 仅保存 AI 文本日志不足以审计真实结算 | JSON 产物增加完整 GameEngine action history 与战斗事件数 |
| P-016 | 从 sim/audits 子目录直接执行时 Python 找不到 engine 包 | 按仓库统一约定向上定位根目录并验证 engine/ 存在后再加入 sys.path |
| P-017 | push 与 pull_request 双触发导致同一随机对局重复跑 | 随机 PvP 工作流保留 PR 与手动入口，移除分支 push 重复触发 |
| P-018 | 测试直接 import sim/audits 下的 CLI 脚本，违反“子目录脚本不作为库 import”的布局约定 | 把角色构建与对局组装提取到 sim/random_pvp_support.py 根库；测试与 CLI 共用根库，并加入布局护栏和 README 目录表 |
| P-019 | 单件遗物＋单道纹的随机角色难以形成清晰流派 | 默认改为高速爆发 vs 持续续航两套预设构筑；双方均25属性点、2件遗物、3种流派道纹＋出生【透支】 |
| P-020 | 首场流派对局中 TacticalAI 未发动道纹，无法观察道纹组合联动 | 已记录为当前实验限制；下一步需要增加道纹使用覆盖检查／专门战术驱动，不把未发生的效果当作已验证 |
| P-021 | 癌变死亡被旧报告归入普通 elimination，导致特殊死亡在汇总统计中失去独立存在感 | 新增 `cancer_death` 分类，并在 Markdown/JSON 报告中汇总结局类型；雕塑、回合上限、程序异常、其他淘汰分别统计 |

## 结局统计口径

- `cancer_death`：死斗返回原因明确包含癌变。
- `sculpture_loss`：因化雕塑离场判负，不计作被击杀。
- `direct_kill`：原始归因明确标注击杀或攻击致死。
- `other_elimination`：其他明确判负结局，保留原始原因供审计。
- `round_limit` / `unresolved` / `simulation_error`：未决或程序问题，不计入胜负率。
- 报告同时保留逐局原始 `reason`，分类只是统计分桶，不修改引擎规则。

## 当前边界

- 当前是 1v1 轮回者对战，不带朋友／员工／造物。
- 默认双方各2件随机遗物、3种预设流派道纹及出生【透支】；尚未随机扩展为多道纹成长构筑。
- 双方使用同一 TacticalAI，不代表生产 LLM AI 的策略水平；首场双方均未发动道纹，流派联动尚未验证。
- 首场样本只证明完整对局管线可运行，不代表构筑平衡或胜率。
- 该实验室只存在于 sim 研究工具，不会进入生产引擎；不会自动封存胜者、改写角色档案或改变正式规则。

## 运行

```bash
python sim/audits/random_pvp_lab.py --runs 1 --seed 20261118
```

GitHub Actions 会上传 JSON 与 Markdown 战报；JSON 内含逐行动真实结算历史。
