### 1C. 错位结论（用户要求的两类标注）

**A. 本该"按次数消耗"却会被【回响】影响**

| 状态 | 实际行为 | 判定 |
|---|---|---|
| **庇护** | 回响把 `remaining_rounds` 3→5，`value`（剩余免疫次数）**不变** | 半错位：延长的是"剩余次数可用的窗口"，不是次数本身。实测 `[('庇护', 2, 5)]` |
| **篡改** | 可被选中；`is_permanent` 为真 → 不写值；日志仍报 `duration_extended before=-1 after=-1` | **纯浪费**：付 5X 法力，零效果 |
| **出土** | 同上 | 纯浪费 |
| **沉溺** | 同上（次数在 value，`-1` 永久） | 纯浪费 |
| **操作** | 同上（一次性） | 纯浪费 |
| **必中（镜像）** | 同上 | 纯浪费 |
| 冰冻 / 波及 / 共罪 / 强化 / 弱化 | `-1` 不会被 `is_expired` 过滤，全部可选 | 纯浪费 |

> 根因：`prepare_huixiang` 的候选筛选只有 `not status.is_expired`（`daowen_effect.py:340-344`），没有"是否为持续型/是否 `is_permanent`"的过滤；应用侧 `if not status.is_permanent` 静默跳过，也不报错。

**B. 本该"持续X回合"却没进 `status_effects`，导致【回响】/【大梦】无法正常交互**

| 机制 | 规则文本 | 现实 |
|---|---|---|
| **豪夺** | "持续X回合" | `stolen_relics` dict；回响选不到、大梦不推进（实测 remaining 恒为 2） |
| **封印X（单位）** | "延后X回合再入场" | `return_round` 字段 |
| **遗物封印** | "持续X回合" | `sealed_relics` 计数 |
| **缓厄沙漏** | "转移到下回合" | `deferred_damage` 列表（无回合号，只能"下一回始"） |
| **必中X** | "接下来X次选中" | `_bizhong_left` 计数器 |
| **出土 / 篡改 / 沉溺 / 操作** | 次数型 | 虽在 `status_effects` 内，但用 `-1` 永久 + `value` 计数，与"持续Y"的通用语义不同构（`回响`/`遗忘` 都只能整体搬动或无效） |
