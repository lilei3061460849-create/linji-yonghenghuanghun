# 供能端、输出端与潜在供能组合审查

日期：2026-10-28。性质：**现有资源组合审查，不新增机制，不替草案定稿**。

## 口径与证据等级

遵循《法术索引》用户定义：供能端有限或无限地产出输出端必须的资源；输出端是致胜方式。有限供能称循环，无限供能称无限。

- 供能和输出可以拆开搭配；不要求供能组合本身杀敌。
- **供能端不要求资源净增加**。唯一分类依据是它能有限或无限地提供输出端必需的资源；原额回充、按需恢复同样可以供能。检查完整组合是否覆盖输出费用，是配对核算，不是给供能端另加“必须净赚”或“输出必须免费”的定义。
- **免付代价、保命、扩容、延时不自动等于供能**；只有接到实际资源生产者、成为输出所必需的资源来源，才按供能端计。
- 无限供应不要求余额存成数值∞；法限有限仍可反复“消耗→回充”。苍白之花是扩容，不是必需的无限供能源。
- 分清：①同一次法术执行内反复结算；②跨角色回合；③跨世界回合；④跨战斗。固定时段内一次启动的药效，不因启动道具耐久有限就必然只能循环有限次；但跨回合必须支付续效。
- 已实现的组件≠完整构筑已经通过API手操。下文“结构成立”指资源闭合；启动、阶级/出手、目标/反应、持续时间和对手反制仍须验证。
- **P：支付/效果探针通过**；**C：按现有正文/代码可推导的条件组合，未做完整构筑验证**；**D：草案/仅有局部实现或无获取途径**。有限次数探针不是无限运行证明，程序loop_guard也不是新增游戏规则。

## 补充纠正：增殖＋永生是无限生命供能候选，不是已验证定稿

- 供能定义不要求净增，增殖＋永生不应被“无净盈余”筛选漏掉：增殖提供无限血限，永生草案在回终回复所有已损生命，具有无限生命供能意图。
- **撤回上一版“按规则组合成立”的过强断言**。永生仍未实现，且将回终触发时机包进道纹，须按道纹标准重做。不能把旧草案直接当正式积木，也不能凭有限回复探针宣布无限回复已验证。
- 若重做后保留相应资源供应能力，可接流血连击/分裂，或透支转法力再接杀伐；这些是候选连接，不是当前可执行构筑。
- 当前癌变实现：持有“无限血限”时`cancer_threshold_of`返回0哨兵，`check_cancer`跳过触发；**没有实际比较“无限回复量”与“无限阈值”**。所以“有限回复不会癌变”不能替代这两者组合的测试。
- 新增两项边界探针：增殖状态下回复300，治疗累计300且不癌变；状态到期后累计不清零，下一次显式癌变检查会命零。这是有限数值/判定入口测试，不是永生施法或完整回终顺序测试。
- 无限血限下“回复所有已损生命”如何表示、是否为无限回复以及癌变怎样比较，尚未实现/定稿，不替用户补一条无限运算规则。

| O6 | **勒索→还债** | 法力 | 每3X法力削10X真碎片/记负债，推进还债特殊胜利；阈值与历史峰值相关，不能写死固定几次获胜 |
| O7 | **再生敌人→癌变** | 法力或攻击力通道，外加有效目标 | 癌变计入过量回复，满血也能推进；坏死、无限血限、熄事可反制。不是以“回血收益”为输出，而是把癌变命零当致胜 |
| O8 | **削速＋削法→雕塑** | 弱化/变形/抢劫等的发动资源 | 两项都归零才雕塑；攻击力与当前法力的实时关系、全力/全速覆盖必须分别核对，不是弱化一次就必成 |

| O12 | **分裂军团＋有效攻击/施法** | 可再生生命＋行动/法力支持 | 血能换复制体，复制体不复制分裂；现行临时朋友的行动限制须核对，不能按“生出来就自动全员无限施法”估算 |
| O13 | **蚀界残钟** | 回终次数，以及敌人的当前法力×速度 | 削血限致胜，自己也受影响；可以搭定向时间推进审查，但“沉溺触发的额外回终是否仍全场作用”须独立实测 |

| O15 | **控制锁→凡庸** | 持续控制、存活与时间 | 束缚仍允许施法，封印暂离不算击杀；要真正封住对手的出手或有效伤害再推进凡庸，不能把普通控制直接宣判获胜 |

必中、破障晶、灼罪钉、豪夺等是输出的命中/穿透/增幅/拆解组件，单独不必然是致胜方式。庇护、缓厄沙漏、叠鳞甲等偏保命/抗输出，不强行塞入供能或致胜类别。

## 四、沉溺＋守夜灯：修正上一轮审查方式

**用户提出“配杀伐/连击作输出端”是合理的构筑方向。** 供能端不必独立致胜。

设世界回合数R；每轮沉溺a、输出法力费b，则未溢出情况下净法力：

`aR - 5a - b`。

- 例：R=10、沉溺1＋杀伐2，法力账为`10-5-2=+3`；不存在“有输出就一定供不起”的问题。
- R=5时沉溺自持但没剩余蓝，不能再免费加收费输出；可查减费或不另收费的触发输出。
- 须有先付沉溺的法力、结算中足够容量，输出排在供能前后会影响周转。
- **凡庸并非只看造成伤害，还看是否出手**，任一连续计数到阈值都会触发。当前`advance_target_rounds`每个额外回合单独清空行动/伤害记录，不给额外行动，结束时更新凡庸。
- 因而“在额外回合外插一次杀伐”，不自动等于“每个额外回合都记录出手”。回始/回终反应输出能否在该额外回合真实触发、是否记为出手，必须分别验证，不能凭有伤害就宣布已解决，也不能用纯空转的死亡否定所有正确接入输出的构筑。
- 沉溺还递减持有者的增殖/两翼等持续效果，不得把不推进时间型供能的持久性结论套过来。

**结论：列为高优先级供能候选；法力账成立。完整无限卡在输出的额外回合接线/行动记账，不是缺少伤害道纹。** 本次不擅自改凡庸、不新增行动机会，也不替用户判定这些记账语义。

## 六、偏爱与接口组件，防止漏查或误分

- **贪婪的偏爱**：现有法力消耗减半，作用类似愤怒，可将再生⇄透支变成有盈余结构；不自带癌变免疫。与愤怒目前是`or`，不能按两次减半算四分之一。
- **永恒的偏爱**：可令该持有者发动产生的有限状态变永久，有望维持增殖等供能保护；不是额外资源本体，不能默认影响消耗品施加的翼/药状态。
- **时间的偏爱**：把冷却按战斗场数改为按回合递减，沉溺可能加速重新可用；不直接产法力，也不是任意在冷却道纹都能发动。
- **饥荒的偏爱**：有效伤害削敌法限，是输出/反供能而非自己的供能。
- 血契是代价分摊，不产生额外资源；分摊给有限朋友不自动无限。
- 净化是回收五类代价的接口：当前20X收费，单靠透支枯竭/疲惫产X再净化花20X不能自持；有外部无限法力时可以反过来维持其他资源。失忆、冷却不能用净化回收。
- 定命丸、震岳龙躯减少后果，苍白之花/猩红果实扩容，叠鳞甲/沙漏保命；这些都是供能结构的修饰件，不独自产出资源。
- 一半伤害可反复延期，不等于产生生命或法力；必须实际发生失血，承露盏/逆血龙鳞才按相应真实事件获益。
- 烬翼回耐久要怪物命零；招魂返场/分裂复制体的真实死亡能否反复作燃料，涉及尸体可再召、复制体种类、死亡幂等及收益归属，**未验证，不把“死一次”当无限尸体源**。

## 七、优先级与本次交付边界

1. **先查I1：不朽＋衰老透支＋杀伐**，资源结构最短、无需回血/癌变处理。
2. **再查I2：齿轮＋超频＋疲惫透支＋回锋刀**，清楚展示“净零供能也能有输出”。
3. **再查I3/I4：增殖把有限血法发动机升级为同段时间内无限候选**，最贴近现有核心道纹。
4. **沉溺＋守夜灯＋杀伐/连击单列做真实额外回合输出接线审查**；不再只测供能空转。
5. 馈赠已废弃，不再推荐；草案优先看苦涩誓言、如愿以偿、目睹；这里只提取潜力，不自动实现或恢复退役道纹。
