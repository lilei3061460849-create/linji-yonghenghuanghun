# 道纹效果汇总（此前未讨论过的部分）

> 口径：本会话中你点名要求处理/排查过的道纹共 17 个——**沉溺、庇护、回响、招魂、豪夺、血契、共罪、催化、出土、分裂、流动、遗忘、唯一、篡改、凋零、压迫、波及**，不计入本文。
> 本文收录其余 **39 个**（含 3 个尚未接入运行时的草案）。只写「名字 + 支付 + 效果」，不写道纹之间的关系。
> 事实源：`engine/daowen.py` 的 `calculate_*` 与 `全道纹索引.md`，两者不一致时以 `规则正文.md` 为准。

## 一、杀伐闭环（通用核心）

| 道纹 | 支付 | 效果 |
| --- | --- | --- |
| 杀伐 | 法力 X | 使 [目标] 生命 -X²。 |
| 再生 | 法力 X ／ 攻击力 4X | 为 [目标] 回复 4X 点生命。 |
| 连击 | 六选一：生命 5X／法力 5X／血限 X／枯竭 X／碎片 5X／假碎片 5X | 选中 [目标] 5X 次，每次对其造成 1 点伤害。支付途径只改价格，效果恒同；碎片与假碎片各扣各自池子。 |
| 束缚 | 冷却 2X | 使 [目标] 只能施法（瞬发或自定义法术），其余主动行动不可用，持续 X。（施法本身放行） |
| 封印 | 异变 X | 使一个 [目标] 延后 X 回合再入场；暂离期间仍阻塞战终，回场当回合沿用增援白板。 |
| 操作 | 法限 X | [目标] 除施法外的**下一次**行动由你决定（攻击／跳过／使用消耗品）。发动时须预指定；未预指定的到该行动时作废，代价不退。 |
| 迟滞 | 冷却 X | 使 [目标] 行动所需出手 +1，持续 X；含闪避、招架这类零出手的回合外行动。 |

## 附：需要留意的实现现状

- **连击**：每段是独立的 `_apply_hostile_damage(subtype="daowen_hit")`，不触发千荆甲。
- **净化**：支付恒为 20X，按选择的 X 结算；选择不合法在扣费前报错。
- **唤潮／蜃景**：仅作用于开放地图；两者都能局外发动（与【真理】同为明示的局外发动项）。
- **炽热／熔化／锻造**：`DaoWenEngine` 注册表里没有这三个（53 个已注册道纹里不含），仅有文档草案。
